Conviction Maintenance

Flush: Clears failed wallet caches so conviction re-computes. Refresh Holders: Re-fetches current holder counts (unique wallets) from Helius DAS for the home tables. Snapshot: Queues a full holder snapshot for every curated token; each one adds a point to the holder chart (snapshots also run on their own every few hours). Backfill: Pulls CoinGecko Pro holder history for curated tokens; it only fills dates before HolDEX's own first count and is shown as an estimate. Refresh Market Caps: Force-fetches latest price/mcap/priceChange24h for all curated tokens from GeckoTerminal in batches of 30 and busts the leaderboard cache.

Wipe Token Cache

Removes ALL cached data for a specific token: price, holders, diamond hands, conviction, charts, wallet hold times, and list/leaderboard caches. Use when a token's data is stale or stuck.
